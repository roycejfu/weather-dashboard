🔬 关键洞察
🔴 Memory 结构性质变 存储从配角跃升为第二大成本项 ($2.0M / 26%)。3D NAND 是最大单一增量 (~$1.2M)，GB300 几乎无此配置。若含 HBM4，存储相关成本近 $2.5M (32%)。
🔵 PCB 不再是"配角" PCB 从 $35K 增至 $117K (+233%)。61% 增量来自三种 GB300 不存在的新模块 (Midplane + ConnectX + BlueField PCB)。层数从 22L→44L，CCL 从 M7→M8。
🟠 网络芯片翻倍扩容 NVSwitch (18→36) + ConnectX (36→72) 数量均翻倍，新增 BlueField DPU。网络总成本 $720K，若含铜缆背板接近 $1M。
🟢 MLCC 单板用量暴增 计算板 MLCC 从 25颗→90颗 (+260%)，新增 BlueField 和 ConnectX 模块。高端 AI 服务器 MLCC 需求强劲，ODM 积极备货。
🔴 GPU 相对"贬值" GPU 绝对金额仍涨 57% ($2.52M→$3.96M)，但 BOM 占比从 63%→51%。AI 基础设施利润从 GPU 向配套组件扩散。
🔵 自研内存的降本潜力 若云厂商直采 LPDDR5X SOCAMM 模组，单机架 ASP 可从 $7.8M 降至 $6.7M (降 $1.1M)。英伟达通过长约锁定低价，再以 70% 毛利率转售。
